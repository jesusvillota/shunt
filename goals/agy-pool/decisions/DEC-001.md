## Question and options

Where should shunt read Antigravity quota from?

- A. Fix the existing HTTP path (`retrieveUserQuotaSummary` with shunt's own `antigravity_oauth` login).
- B. Run `agy -p /usage --output-format json` per account (Orca's method). Free, needs agy >= 1.1.11 and a `profile_dir` per account.
- C. Both: B as primary, A as fallback.

Criteria: works for all 6 accounts, spends no quota, no secrets in shunt, low latency.

## Evidence

Orca: `src/main/rate-limits/antigravity-usage-*.ts` in https://github.com/stablyai/orca. Shunt: `src/auth/antigravity/usage.rs`, `docs/notes/antigravity-quota-observation.md`. TASK-001's report adds live evidence.

## Recommendation

Planner lean (before TASK-001 evidence): C. Orca shows B works without spending quota; keep A where it already works.

## Decision


Accepted by jesusvillota on 2026-10-14: Owner chose option C: agy /usage (B) as primary quota source, existing HTTP path (A) as fallback where it already works. Orca shows B works without spending quota.
