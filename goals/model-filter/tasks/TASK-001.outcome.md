## Summary
Adds `src/models_prefs.rs`, `src/models_catalog.rs`, the `shunt models` command and the Models dialog in `shunt tui`. State lives in `~/.shunt/models.json` (overrides only). Verified at the PR head of this branch. An independent review found four issues that are fixed in this PR: a config log line could draw over the TUI (tracing is silenced for the agy config read); quick toggles could save out of order (saves are now queued and the newest snapshot is written); date-like tokens (`0905`, `2411`) counted as versions and `max` merged `codex-max` with `codex` (both fixed); a late `ModelsOpened` could replace or hide behind another dialog (ignored now).
Known and left as is: a corrupt `models.json` is treated as defaults and overwritten by the next toggle (same as `top.json`); two `shunt tui` instances overwrite each other's file; `shunt models` can take over a minute when all three CLIs hang (30 s each, run in turn). Deviation from the plan: `shunt models --json` has no `--all` flag; every model is always listed with `active` and the consumer applies `filter`. The docs say `goal` refuses a switched-off model; that ships in the `model-filter-consumer` goal in the config repo. Follow-up: without `--features tui`, clippy on tests already fails on an unused import in `src/routing/stage/store.rs:50` (not touched here).
